Short note on each diagram:

- Proposed System Architecture
  - should show student side, admin side, web app, database, and exam monitoring flow

- Use Case Diagram
  - should show what the admin can do and what the student can do

- Student Exam Process Flowchart
  - login -> verify -> start exam -> answer questions -> submit -> result

- Admin Exam Management Flowchart
  - login -> create exam -> add/import questions -> manage students -> monitor sessions -> export result

- Anti-Cheat Monitoring Flow
  - detect violation -> log violation -> increase warning count -> check limit -> terminate or continue

- ERD
  - should include tables like students, exams, questions, sessions, answers, violations
